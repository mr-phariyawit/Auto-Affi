## 7. กฎ originality สำหรับเรา

**สรุป: ยืมได้เฉพาะ "โครงสร้างและจังหวะ"; หัวข้อ ถ้อยคำ ตัวละคร สี ตัวอักษร และลูกเล่นเฉพาะตัวต้องเป็นของเราเอง** (ข้อมูลทั่วไป ไม่ใช่คำแนะนำทางกฎหมาย; กฎหมายลิขสิทธิ์ไทยยังไม่ได้ค้น [REPORT])

| ใช้ซ้ำได้ (แนวคิด/ธรรมเนียมทั่วไป) | ต้องเป็นของเรา (expression ของเขา) |
|---|---|
| คำถามค้างจอตั้งแต่เฟรม 0 + counter สด + เฉลยท้าย | **หัวข้อทั้ง 24** และกลไกในรายการท้ายข้อ 2 |
| จอเดียวไม่ตัด, โซนแนวตั้งคงที่, เว้นล่างกัน UI | **ถ้อยคำ title/caption/stamp** แบบคำต่อคำ รวมสูตรประโยค "Just N …!" และ "N …: taller than the universe!" |
| จังหวะ: pay-off ≤2 s, 1 ขั้น/วินาที, เฉลย → twist → การ์ดจบ | **Mascot มะม่วง**, stick person ชมพู "YOU", หน้า kawaii ชุดเดียวกัน |
| หน่วยปรับเอง, comma, เลขยาวเป็น visual | **Watermark/handle** และตำแหน่ง–สไตล์เดียวกันเป๊ะ |
| บันไดเทียบกับของจริง (แนวคิด) | **ชุดสี + ตัวอักษร + layout ที่ยกมาทั้งชุด**: navy เข้ม + neon mint/ทอง + sans มนหนา |
| zoom โดยย่อโลกรอบตัวเอก; magnifier เมื่อของเล็ก | **ชุด ladder ของเขายกทั้งชุด** (dice→mug→cat→you→house→Pisa→Eiffel→Burj→Everest→Space→Moon) |
| loop ไร้รอยต่อ (แนวคิด) | **Rewind แบบของเขา**: ไอคอน "◀◀" + scan-line VHS + เล่นถอยหลัง |
| ข้อเท็จจริงทางคณิต/ฟิสิกส์ | **Footage, เสียง** ของเขา; diagram วงกลม chord ของ C03 ในหน้าตาเดิม |

- โค้ดใน repo `3b1b/videos` เป็น **CC BY-NC-SA 4.0** (ตาม `simulation_math.md` ที่อ้าง README ของ repo) → **ห้ามคัดลอกหรือดัดแปลงโค้ดนั้น** เข้าช่องที่หารายได้; เขียน simulation เองจากคณิตศาสตร์ และให้เครดิตเจ้าของผลลัพธ์ใน caption (เช่น Galperin 2003) [REPORT, GROWTH §6]
- ความเสี่ยง platform: YouTube "inauthentic content" เล็งคลิปที่ดูทำจาก template ซ้ำ ๆ → แต่ละคลิปต้องเป็น concept ใหม่จริงและเฉลยต้องอธิบาย "ทำไม" [GROWTH §5]

**ทิศทาง visual identity ของซีรีส์เรา (ทิศทางเท่านั้น ยังไม่ได้ออกแบบ)**
- พื้นหลัง **ไม่ใช่ navy + neon**: เลือกโลกวัสดุหนึ่งอย่างเป็นลายเซ็น เช่น กระดาษ/โต๊ะทำงานโทนอุ่นกับหมึกทึบ หรือกระดานดำชอล์ก — ทดสอบการอ่านบนจอมือถือก่อนล็อก
- ตัวอักษรไทยเป็นตัวหลัก (ฟอนต์ที่ Thai-safe ตามกฎ HyperFrames ใน `docs/reference/hyperframes-components.md`) คำถามไทยใหญ่ + อังกฤษเล็ก หรือกลับกันตามคำตอบข้อ 9
- Counter เป็น **วัตถุในฉาก** (เช่น เครื่องนับแบบลูกกลิ้ง/ป้ายพลิก) ไม่ใช่บรรทัดข้อความลอยใต้ title
- พิธีกร = **หุ่นยนต์ของแบรนด์สายตำ** (มีอยู่แล้ว) แทนผลไม้; ใช้เป็นตัวชี้/ตัวรับมุก ไม่ต้องอยู่ทุกคลิป
- Ladder ใช้ **ของไทย/เอเชียที่ผู้ชมเรารู้จัก** (ตึก ภูเขา ของกินของใช้) — ความสูง/ขนาดทุกค่าต้องตรวจแหล่งก่อนขึ้นจอ [ต้องตรวจ]
- สี accent คู่เดียวที่ไม่ใช่ mint+ทอง; สีบอกสถานะ (ถูก/ผิด/กำลังนับ) กำหนดครั้งเดียวใช้ทั้งซีรีส์
- ตอนจบ loop ด้วยกลไกของเราเอง เช่น counter หมุนกลับศูนย์แบบเครื่องนับ หรือ match-cut ที่เฟรมสุดท้ายมีองค์ประกอบเดียวกับเฟรม 0 — ไม่มี "◀◀" และ scan-line
- เสียงออกแบบเองทั้งหมด (tick ต่อเหตุการณ์ + เสียงเฉลย) เพราะของเขาเราไม่เคยได้ยิน
