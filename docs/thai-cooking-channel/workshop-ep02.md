# Workshop: ทำตอนที่ 2 ของช่องอาหารไทย

ทำตามลำดับ แต่ละขั้นบอกก่อนว่าเริ่มจากตรงไหน แล้วค่อยบอกว่าทำอะไร ข้อสั่งใน `code` รันจากโฟลเดอร์ `Auto-Affi` เว้นแต่จะบอกไว้
ก่อนเริ่ม อ่าน [ep01-retro.md](ep01-retro.md) และ [rules.md](rules.md) หลังจบแต่ละขั้น ตรวจตามแถวของขั้นนั้นใน [soul-checklist.md](soul-checklist.md)

ตัวย่อ: `EP` = `output/thai-cooking-channel/ep02-<slug>/` (เช่น `ep02-tom-yum`)

## ขั้น 0 — ตัดสินเรื่องที่ค้าง

**เริ่มจาก:** แชทกับเจ้าของช่อง
1. ขอให้เลือก: เมนูตอนที่ 2, แนวภาพ (พิกเซลผสมภาพจริง หรือ หมึก + สีกวอช), เพดานเงินสร้างภาพรอบนี้
2. สร้างโฟลเดอร์ `EP` และไฟล์ `EP/README.md` จดคำตอบพร้อมวันที่

## ขั้น 1 — ค้นคว้ารสดั้งเดิมและสี่เสา

**เริ่มจาก:** โฟลเดอร์ `reports/` (ดูตัวอย่าง `reports/ผัดกะเพรา รสดั้งเดิมและสี่เสา.md`)
1. หาแหล่งที่บอก "ดั้งเดิม" ของเมนูนี้ (ตำราไทยเก่า พร้อมปี) และแหล่งครัวไทยที่เชื่อถือได้
2. แยกตามสี่เสา: เครื่องปรุง ผักไทย เครื่องเทศ เนื้อสัตว์
3. ทำตาราง ประโยค | สถานะ (ใช้ได้ / ห้ามใช้ / ข้อถกเถียง) | แหล่ง URL ที่เปิดจริง
4. ทำตารางหาซื้อในต่างประเทศ (ของแห้งส่งได้ ผักสดส่วนใหญ่ส่งไม่ได้)

## ขั้น 2 — เขียนบทพากย์และซับไตเติล

**เริ่มจาก:** คัดลอก `ep01-pad-kra-pao/script/vo-script-v1.md` ไปเป็น `EP/script/vo-script-v1.md`
1. แบ่ง 7–8 ช่วง ช่วงสุดท้ายเป็นการ์ดท้าย
2. แต่ละช่วงมี: ภาพ | บรรทัดอังกฤษ (พากย์ + ซับหลัก) | บรรทัดไทย (ซับรอง) | แหล่ง
3. บรรทัดอังกฤษสั้น ราว 6–10 คำต่อช่วง
4. ส่งให้เจ้าของช่องอนุมัติ ห้ามสร้างเสียงก่อนได้คำอนุมัติ

## ขั้น 3 — สร้างภาพ

**เริ่มจาก:** `output/thai-cooking-channel/assets/manifest.json`
1. เพิ่มรายการภาพของตอนนี้ลง manifest (id, pillar, dir, status `prompt-pending`) และเขียน `prompt.txt` ของแต่ละภาพ
2. ส่ง prompt + เพดานเงินให้เจ้าของช่องตรวจ (ด่านตรวจก่อนสร้าง)
3. ทดลองก่อน: `python3 tools/thai-assets-gen.py --ids <id> --dry`
4. สร้างจริง: `python3 tools/thai-assets-gen.py --ids <id1>,<id2>`
5. ตรวจภาพทีละตัว เขียน `qa.md` คัดตัวผ่านเป็น `final.png`

## ขั้น 4 — เสียงพากย์

**เริ่มจาก:** `EP/audio/vo-en-v1/`
1. ทีละบรรทัด:
   `python3 tools/gemini-tts.py --model gemini-2.5-pro-preview-tts --voice Sulafat --text "Say at a brisk, lively pace, like a warm confident cooking-show narrator: <line>" --out EP/audio/vo-en-v1/l01.wav`
2. ถอดเสียงกลับด้วย `tools/gemini-stt.py` เทียบกับบท ถ้าไม่ตรง ถอดซ้ำหนึ่งครั้งก่อนสร้างใหม่
3. จดความยาวจริงของแต่ละบรรทัด (อยู่ในไฟล์ `.json` ข้างไฟล์เสียง) เป็นจุดเริ่มของแต่ละช่วง (`SEG`)

## ขั้น 5 — ดนตรีและเสียงประกอบ

**เริ่มจาก:** `ep01-pad-kra-pao/audio/music/request.json`
1. ใช้ดนตรีของตอนที่ 1 ซ้ำได้ ถ้าเจ้าของช่องไม่ขอใหม่ ถ้าขอใหม่ ส่ง request แบบเดียวกันไป kie.ai Suno V6 (12 credits ได้ 2 แบบ)
2. เสียงประกอบสังเคราะห์ด้วย ffmpeg ตามตัวอย่างใน `ep01-pad-kra-pao/audio/sfx/synth/`
3. ผสม: เสียงพากย์ + ดนตรีลดเสียงตอนพากย์ + เสียงประกอบ ให้ได้ราว -14 LUFS

## ขั้น 6 — ภาพเคลื่อนไหว

**เริ่มจาก:** แนวภาพที่เลือกในขั้น 0
- **พิกเซลผสมภาพจริง:** คัดลอก `demo/pixel-style-demo/` ไปที่ `EP/pixel/` แก้ `STEPS` วัตถุดิบ ภาพ และ `SEG` แล้ว `python3 build.py`
- **หมึก + สีกวอช:** คัดลอก `ep01-pad-kra-pao/animatic-v2/index.html` (ผัง v2) แล้วใส่ภาพและเวลาจากขั้น 4
- เปิดดูในเบราว์เซอร์ในแอป: `cd EP/pixel && python3 -m http.server 8931` แล้วเปิด `http://localhost:8931/index.html?render=1` ลองเลื่อนเวลาด้วย `window.__seek(<วินาที>)`

## ขั้น 7 — ซับไตเติล

**เริ่มจาก:** ไฟล์หน้าเว็บของขั้น 6 (pixel `template.html` หรือ HyperFrames `index.html`)
1. เพิ่มกล่องซับใต้ภาพ: บรรทัดอังกฤษขนาดหลัก บรรทัดไทยราว 60–65% ของขนาดอังกฤษ
2. ข้อความแต่ละช่วงมาจากบท ช่วงเวลาเดียวกับ `SEG`
3. ตรวจว่าซับไม่ทับการ์ดขั้นตอน เชฟ หรือลายน้ำ และอยู่ในพื้นที่ปลอดภัย
4. ทำการ์ดท้ายสองแบบ: แบบมี Shopee (Facebook / Instagram / YouTube) และแบบไม่มี (TikTok)

## ขั้น 8 — เรนเดอร์

**เริ่มจาก:** `ep01-pad-kra-pao/pixel-v1/capture.cjs` (แก้ `END` และ URL ให้ตรงตอนใหม่)
1. `node capture.cjs EP/frames` (30 fps)
2. `ffmpeg -framerate 30 -i EP/frames/f%05d.png -i EP/audio/mix.wav -c:v libx264 -crf 16 -pix_fmt yuv420p -c:a aac -b:a 192k -movflags +faststart EP/final/ep02-v1.mp4`
3. ทำซ้ำสำหรับเวอร์ชัน TikTok (การ์ดท้ายไม่มี Shopee)
4. ตรวจตามแถว 8 ใน soul-checklist

## ขั้น 9 — ลิงก์ affiliate

**เริ่มจาก:** เบราว์เซอร์ในแอป ล็อกอิน Shopee ด้วยบัญชี affiliate ของสายตำ → `https://affiliate.shopee.co.th/offer/product_offer`
1. ค้นสินค้าที่ตรงกับแต่ละขั้น เปิดหน้าสินค้า กด "เอา ลิงก์" คัดลอกลิงก์สั้น
2. ตรวจ: `curl -s -o /dev/null -w '%{redirect_url}\n' <ลิงก์>` ต้องมีรหัสสินค้าตรงกัน
3. บันทึกใน `EP/affiliate-links.md` พร้อมราคา ยอดขาย ค่าคอม ณ วันสร้าง

## ขั้น 10 — โพสต์

**เริ่มจาก:** Postiz (`npx --yes postiz integrations:list`)
1. อัปโหลด: `npx --yes postiz upload EP/final/ep02-v1.mp4` (และไฟล์เวอร์ชัน TikTok)
2. เขียนแคปชันสองภาษาแยกตามแพลตฟอร์มตาม rules.md ข้อ 4 แล้วส่งให้เจ้าของช่องอนุมัติ
3. โพสต์ (TikTok ใช้ `DIRECT_POST`) แล้วรอสถานะ PUBLISHED
4. เปิดโพสต์จริงทุกแพลตฟอร์ม ดูว่าคลิปเล่น แคปชันครบ ป้ายโฆษณาและป้าย AI ขึ้น
