## 2. สายการผลิตที่ใช้จริง (ตามลำดับ)

1. **ค้นคว้า** รสดั้งเดิมและสี่เสา (เครื่องปรุง ผักไทย เครื่องเทศ เนื้อสัตว์) → ตาราง "ใช้ได้ / ห้ามใช้" ใน `reports/ผัดกะเพรา รสดั้งเดิมและสี่เสา.md` ทุกบรรทัดพากย์ต้องมาจากแถว "ใช้ได้"
2. **บทพากย์** 8 ช่วง แต่ละบรรทัดมีแหล่งอ้างอิง → `ep01-pad-kra-pao/script/vo-script-v1.md`
3. **ภาพประกอบ** GPT Image 2.5 Sunburst ผ่าน OpenRouter ด้วย `tools/thai-assets-gen.py` (manifest เป็นแหล่งความจริง เพดาน USD 5 ใช้ไปราว USD 1.20)
4. **เสียงพากย์** gemini-2.5-pro-preview-tts เสียง Sulafat ด้วย `tools/gemini-tts.py` ตรวจด้วย `tools/gemini-stt.py`
5. **ดนตรี** Suno V6 ผ่าน kie.ai (12 credits) **เสียงประกอบ** สังเคราะห์ด้วย ffmpeg (เจ้าของช่องรับว่าพอใช้)
6. **Animatic v3** HyperFrames จับเวลาจากเสียงพากย์จริง ผัง v2 (หัวเรื่อง → แถบขั้น → มาตรรส → การ์ด → ภาพ) ได้รับอนุมัติเป็นมาตรฐาน
7. **เดโมพิกเซล** (เชฟพิกเซล + ภาพจริงด้านล่าง) `demo/pixel-style-demo/` → `python3 build.py` → โหมดเรนเดอร์ `?render=1` ใช้ `window.__seek()` ตามเวลาเสียงพากย์ → `pixel-v1/capture.cjs` จับภาพ 30 fps → ffmpeg รวมกับเสียงผสม
8. **เผยแพร่** อัปโหลดผ่าน Postiz → TikTok แบบ DIRECT_POST
