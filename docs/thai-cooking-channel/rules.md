# กติกาช่องอาหารไทย สายตำ

ปรับล่าสุด: 18 พ.ย. 2026 · ที่มาของแต่ละข้ออยู่ใน [ep01-retro.md](ep01-retro.md)
ข้อที่ขัดกัน ให้ข้อที่วันที่ใหม่กว่าชนะ ถ้าไม่แน่ใจให้ถามเจ้าของช่อง

## 1. เนื้อหา

1. แกนของช่องคือ **สอนทำให้ได้รสไทยดั้งเดิม** ความลึกอยู่ใต้สี่เสา: เครื่องปรุง ผักไทย เครื่องเทศไทย เนื้อสัตว์ไทย
2. ทุกประโยคในเสียงพากย์และบนจอต้องมาจากแหล่งที่เปิดอ่านจริง และอยู่ในแถว "ใช้ได้" ของตารางค้นคว้าประจำตอน
3. คำว่า "ดั้งเดิม" ต้องบอกว่าดั้งเดิมของใครหรือปีไหน ห้ามใช้ "ต้นตำรับแท้ / authentic original" ลอย ๆ
4. ไม่พูดเรื่องที่ยังเป็นข้อถกเถียงว่า "ผิด" ไม่เอ่ยชื่อยี่ห้อในเสียงพากย์
5. ผู้ชมหลักอยู่ต่างประเทศ ข้อความ "หาซื้อที่ไหน" ต้องเป็นวิธีหาในประเทศของผู้ชม ไม่ใช่สั่งจากไทย (ผักสดส่งออกหลายประเทศไม่ได้)

## 2. ภาพและเสียง

1. เสียงพากย์: ภาษาอังกฤษ gemini-2.5-pro-preview-tts เสียง Sulafat รูปแบบ "Say at a brisk, lively pace, like a warm confident cooking-show narrator: <line>"
2. **ซับไตเติล (ตั้งแต่ตอนที่ 2): อังกฤษเป็นบรรทัดหลัก ไทยอยู่ใต้ ตัวเล็กกว่า** ข้อความไทยมาจากคอลัมน์ไทยของบท ไม่แปลอัตโนมัติตอนเรนเดอร์
3. ตัวหนังสืออื่นบนจอเป็นภาษาอังกฤษ ชื่อไทยเขียนแบบถอดเสียง (nam pla thae, kaphrao)
4. จับเวลาภาพจากเสียงพากย์จริง ไม่ใช่จากการประมาณจำนวนคำ (บรรทัดสั้นใช้ราว 0.45–0.5 วินาทีต่อคำ)
5. ผังจอ v2: หัวเรื่อง → แถบขั้น → มาตรรส → การ์ด → ภาพ ตัวหนังสือทั้งหมดอยู่ในพื้นที่ปลอดภัย
6. ภาพสร้างด้วย GPT Image 2.5 Sunburst ผ่าน OpenRouter มีเพดานเงินต่อรอบ และต้องผ่านการตรวจ prompt ก่อนสร้าง
7. แนวภาพของตอนที่ 2 ต้องให้เจ้าของช่องเลือกก่อนเริ่ม (พิกเซลผสมภาพจริง แบบตอนที่ 1 ที่โพสต์ หรือหมึก + สีกวอช ที่เลือกไว้ 16 พ.ย.)
8. ความดังรวมราว -14 LUFS พีคไม่เกิน -1 dBTP

## 3. ชื่อบัญชีและลายน้ำ

1. ลายน้ำต้องตรงกับบัญชีที่จะโพสต์จริง ดึงชื่อจาก Postiz ก่อนเรนเดอร์ (TikTok สายตำ = @saitum528)
2. ซูมเช็คลายน้ำที่ขนาดจริง ฟอนต์พิกเซลทำให้ 5 ดูเป็น S
3. ห้ามเขียน "ลิงก์ในไบโอ" ถ้ายังไม่ได้เปิดโปรไฟล์ดูว่ามีลิงก์จริง

1. สร้างจากบัญชี Shopee Affiliate ของสายตำเท่านั้น (บัญชีอื่นที่ล็อกอินไว้ไม่ใช่สมาชิก affiliate)

## 6. การโพสต์

1. เจ้าของช่องอนุมัติแคปชันก่อนโพสต์สาธารณะทุกครั้ง
2. ตรวจครบทุกด่านใน [soul-checklist.md](soul-checklist.md) ก่อนโพสต์ครั้งแรก ห้ามโพสต์ซ้ำเพื่อแก้
3. หลังโพสต์ ต้องเปิดโพสต์จริงดู ไม่ใช่เชื่อสถานะ PUBLISHED อย่างเดียว
4. repo นี้เป็นสาธารณะ ห้ามเก็บรูปบัตรหรือข้อมูลส่วนตัวในโปรเจกต์ และถามก่อน push ทุกครั้ง
