# Soul checklist — ด่านตรวจก่อนรายงานว่า "เสร็จ"

หลักเดียว: **ผลิตแล้ว ≠ ตรวจแล้ว** ห้ามบอกเจ้าของช่องว่าขั้นไหนเสร็จ จนกว่าจะรันการตรวจในแถวนั้นและเก็บหลักฐานไว้
ถ้าตรวจไม่ได้ ให้รายงานว่า "ผลิตแล้ว ยังไม่ได้ตรวจ" พร้อมเหตุผล อย่าให้เจ้าของช่องเป็นคนเจอปัญหาเอง

| ขั้น | ต้องตรวจอะไร | หลักฐานที่เก็บ |
|---|---|---|
| 1 ค้นคว้า | ทุกประโยคที่จะใช้มี URL ที่เปิดอ่านจริง | ตาราง "ใช้ได้ / ห้ามใช้" พร้อม URL และวันที่เปิด |
| 2 บท | บรรทัดอังกฤษ ไทย และแหล่ง ครบทุกช่วง เจ้าของช่องอนุมัติแล้ว | ข้อความอนุมัติของเจ้าของช่อง (คำพูดจริง วันที่) |
| 3 ภาพ | เปิดดูภาพทุกตัวที่ขนาดจริง เทียบเกณฑ์ใน prompt ยอดเงินไม่เกินเพดาน | `qa.md` ต่อภาพ, `manifest.json` ยอด spent |
| 4 เสียงพากย์ | ถอดเสียงทุกบรรทัดกลับมาตรงกับบท คำไทยถอดเสียงออกมาถูก | ผล STT ต่อบรรทัด |
| 5 เสียงผสม | วัดความดังราว -14 LUFS พีคไม่เกิน -1 dBTP ถอดเสียงทั้งเพลงยังตรงบท | ผลวัด ebur128, ผล STT ของไฟล์ผสม |
| 6 ภาพเคลื่อนไหว | ลองเล่นแบบที่ผู้ใช้เล่นจริง (กดปุ่มจริง เล่นอัตโนมัติ) ไม่ใช่แค่ตั้งเวลาเอง วัดตำแหน่งกล่องด้วย DOM ว่าไม่ทับกัน | ภาพหน้าจอ + ค่าที่วัด |
| 7 ซับไตเติล | ซับทุกช่วงตรงกับเสียงพากย์ อังกฤษใหญ่ ไทยเล็ก ไม่ทับการ์ด เชฟ ลายน้ำ **เทียบข้อความซับกับบทที่อนุมัติด้วยโปรแกรมทีละตัวอักษร** (ตอนที่ 2 เจอคำหาย สะกดเพี้ยน และบรรทัดถูกตัดสั้น) **และวัดขอบกล่องซับด้วย DOM เทียบตัวเลขพื้นที่ปลอดภัย** (ตอนที่ 2 ขอบขวาอยู่ที่ x 896 เกินขีด 780) | ภาพเฟรมกลางของทุกช่วง + ผลเทียบข้อความ + ค่าขอบกล่อง |
| 8 MP4 | ความยาว ขนาด 1080×1920 30 fps มีเสียง ดึงเฟรมทุกช่วงมาทำแผ่นรวมแล้วเปิดดู ซูมลายน้ำว่าตรงบัญชีที่จะโพสต์ | `ffprobe`, แผ่นรวมเฟรม, ภาพซูมลายน้ำ |
| 9 ลิงก์ | ทุกลิงก์ redirect ไปรหัสสินค้าที่เลือก | ผล `curl` ต่อลิงก์ |
| 10 โพสต์ | สถานะ PUBLISHED แล้วเปิดโพสต์จริง: คลิปเล่น แคปชันครบถึงท้าย ป้ายโฆษณา / ป้าย AI ขึ้น ไม่มีลิงก์ Shopee บน TikTok | URL โพสต์ + ภาพหน้าจอ |

## ก่อนส่งข้อความรายงาน ถามตัวเอง

1. ฉันกำลังบอกว่าอะไร "เสร็จ" ที่ยังไม่ได้ตรวจจริงหรือเปล่า
2. ถ้าเจ้าของช่องเปิดดูตอนนี้ จะเจออะไรที่ฉันยังไม่ได้บอกไหม
3. สิ่งที่ฉันตรวจไม่ได้ (เช่น ฟังเสียง) ฉันบอกไว้ชัดหรือยัง
