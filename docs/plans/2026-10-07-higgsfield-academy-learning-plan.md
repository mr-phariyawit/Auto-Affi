# แผนเรียน Higgsfield Academy ให้ครบทุกอย่าง

สร้าง: 2026-10-07 · สถานะ: **แผน — ยังไม่เริ่มเรียน**

## 1. ขอบเขต (ตัวหาร) — นับจากเว็บจริงวันนี้

| ส่วน | จำนวน | ที่มา | ตรวจแล้ว? |
|---|---|---|---|
| คอร์ส | 16 | `/academy/courses` render ใน browser | ✔ นับ 2026-10-07 |
| บทเรียน (module) | 171 | ผลรวม module ของ 16 คอร์ส | ✔ ตรงกับ Bible เดิม |
| ความยาววิดีโอรวม | ~358 นาที (~6 ชม.) | ตัวเลขบนการ์ดคอร์ส | ✔ จากการ์ด ยังไม่ได้วัดไฟล์จริง |
| Prompt Bank (camera movements) | 46 prompt ใน 6 หมวด | `/academy/apps/prompt-bank` | ✔ นับจาก filter; ยังไม่ยืนยันว่ามี section อื่นอีกหรือไม่ |
| หน้ารายละเอียดคอร์ส | 16 | `/academy/courses/<slug>` | ยังไม่เปิดครบ |

แต่ละบทเรียนมี 4 ชั้นข้อมูล — ต้องครบทั้ง 4 จึงนับว่า "เรียนแล้ว":

1. **Article** — ข้อความบทความใต้วิดีโอ (Bible เดิมอ่านชั้นนี้แล้ว)
2. **Chapters / Keypoints** — แท็บข้างวิดีโอ (บางบทว่าง เช่น A03.01 "No keypoints")
3. **เสียงในวิดีโอ** — สิ่งที่ผู้สอนพูด (Bible เดิม **ไม่ได้ฟัง**)
4. **ภาพในวิดีโอ** — UI ที่กด, ค่า setting, prompt ที่โชว์บนจอ, ผลลัพธ์ (Bible เดิม **ไม่ได้ดู**)

Bible ฉบับ 2026-10-05 ครอบคลุมแค่ชั้น 1 (`reading_scope: lesson text only; not all videos watched`)
→ ช่องว่างที่ต้องปิด = ชั้น 2–4 ของ 171 บท + Prompt Bank 46 + หน้าคอร์ส 16

## 2. นิยาม "เรียนแล้ว" ต่อบท (ต้องมีหลักฐานทุกข้อ)

| ชั้น | หลักฐานที่ต้องมีในไฟล์ |
|---|---|
| Article | ข้อความเต็ม + sha256 |
| Chapters/Keypoints | รายการ timestamp + หัวข้อ หรือบันทึก "ว่าง" |
| เสียง | transcript เต็มพร้อม timestamp; ความยาว transcript สอดคล้องกับความยาววิดีโอ |
| ภาพ | frame ทุกจุดเปลี่ยนฉาก + OCR ของ prompt/setting บนจอ |
| สรุป | notes: เทคนิค, prompt ที่ใช้จริง, model+setting, ข้อผิดพลาดที่ผู้สอนเตือน, ต่างจาก article ตรงไหน |

ไม่มีหลักฐานครบ = สถานะ `PRODUCED` หรือ `PENDING` ห้ามนับเป็น `VERIFIED`

## 3. Coverage ledger — กลไกที่ทำให้มั่นใจว่าครบ

ไฟล์: `output/higgsfield-academy-study/ledger.csv` หนึ่งแถวต่อหนึ่งหน่วย (171 + 46 + 16 = **233 แถว**)

คอลัมน์: `unit_id, type, course, title, url, video_sec, article, keypoints, audio, visual, notes, status, verified_by, verified_at`

- ตัวหารล็อกตั้งแต่ Phase 0 — ถ้าเว็บเพิ่มบท ledger ต้องเพิ่มแถว ไม่ใช่ลืม
- รายงานความคืบหน้า = นับจาก ledger เท่านั้น เช่น `VERIFIED 40/233 · PRODUCED 12 · PENDING 181`
- Ledger เขียนลงไฟล์ทุกบท → งานหยุดกลางทางแล้วต่อได้โดยไม่ต้องเริ่มใหม่

## 4. ขั้นตอน

| Phase | งาน | Gate ผ่านเมื่อ |
|---|---|---|
| **0. Inventory** | crawl 16 คอร์ส → ได้ URL บทเรียน 171 ลิงก์จริง + ความยาววิดีโอ; เทียบกับ `course-lesson-index.csv` เดิม; เปิด Prompt Bank ทุกหมวด; สร้าง ledger 233 แถว | ledger มี 233 แถว, ทุกแถวมี URL ที่เปิดได้ |
| **1. Pilot 1 บท** | ทดสอบช่องทางดึงเสียง/ภาพกับ A03.01 (1:59 นาที): มี caption track หรือไม่ → ถ้ามีใช้เลย; ถ้าไม่มี → ดึงเสียงมาถอดความ; ดึง frame ด้วย ffmpeg | transcript + frames ของบทเดียวครบ และคนตรวจเทียบกับวิดีโอได้ว่าไม่ตกหล่น |
| **2. เรียน 16 คอร์ส** | subagent 1 ตัวต่อคอร์ส (ทำทีละ 3–4 คอร์ส) ทำครบ 4 ชั้นต่อบท เขียนผลลง `output/higgsfield-academy-study/<course>/<lesson>/` แล้วอัปเดต ledger | ทุกบทของคอร์สมีหลักฐานครบตามข้อ 2 |
| **3. Prompt Bank** | เก็บ 46 prompt ตัวเต็ม + หมวด + วิดีโอตัวอย่าง (ดูภาพประกอบ) | 46/46 แถว VERIFIED |
| **4. Audit อิสระ** | agent `audit-lead` (ไม่ใช่ตัวที่เรียน) สุ่มตรวจ ≥10% ต่อคอร์ส (≥1 บท/คอร์ส): เปิดวิดีโอจริง เทียบ transcript/notes; ผิดเกินเกณฑ์ → คอร์สนั้นกลับไป Phase 2 | ทุกคอร์สผ่านการสุ่มตรวจ |
| **5. Synthesis** | Bible v2 (เพิ่มสิ่งที่อยู่ในวิดีโอแต่ไม่อยู่ใน article) + อัปเดต 9 skill ใน `skills/higgsfield/` + diff รายงานว่า v2 เพิ่มอะไรจาก v1 | ทุกข้อใน Bible v2 อ้างถึง unit_id ใน ledger ได้ |
| **6. ทดสอบความเข้าใจ** | คุณถามอะไรก็ได้จาก academy (หรือสุ่ม 20 คำถามจาก ledger) → ตอบพร้อมอ้างบท+timestamp | ตอบถูกพร้อมอ้างที่มาได้ |

## 5. สิ่งที่ต้องได้รับอนุมัติก่อน

| ข้อ | ทำไม |
|---|---|
| **ดาวน์โหลดวิดีโอ/เสียงจาก higgsfield.ai** มาเก็บในเครื่องเพื่อถอดความและตัด frame | การดาวน์โหลดไฟล์ต้องได้รับอนุญาตทุกครั้ง; รวม ~6 ชม. (ขนาดยังไม่ทราบจนกว่า pilot) และควรเช็กเงื่อนไขการใช้งานของ Higgsfield; ใช้เพื่อเรียนส่วนตัว ไม่เผยแพร่ซ้ำ |
| **ติดตั้งเครื่องมือถอดเสียง** ถ้าไม่มี caption: `mlx-whisper` (ฟรี รันในเครื่อง Apple Silicon) | ตอนนี้มีแค่ `ffmpeg`; ไม่มี whisper ในเครื่อง |
| **Login Higgsfield** (ถ้า pilot พบว่าวิดีโอบางส่วนต้อง login) | ผมใส่รหัสผ่านให้ไม่ได้ — คุณ login เองใน browser pane |

ถ้าไม่อนุมัติการดาวน์โหลด: ทางสำรองคือเล่นวิดีโอใน browser แล้วจับ caption/screenshot ทีละช่วง — ช้ากว่ามากและเสียงจะครอบคลุมได้เฉพาะถ้ามี caption track

## 6. ต้นทุนและความเสี่ยง

- เครดิต Higgsfield: **0** — แผนนี้ไม่สร้าง media
- ถอดเสียง: ฟรีถ้าใช้ mlx-whisper ในเครื่อง
- Context: งานหนักอยู่ใน subagent ต่อคอร์ส; thread หลักเห็นแค่ ledger + สรุป
- ความเสี่ยง: เว็บเปลี่ยนโครงสร้าง/เพิ่มบท → Phase 0 รันซ้ำก่อน Phase 5 เพื่อเช็กตัวหาร
- สิ่งที่แผนนี้ **ไม่** พิสูจน์: เทคนิคในคอร์สใช้ได้จริงกับงาน Auto-Affi — ต้องทดลองสร้างจริงแยกต่างหาก
