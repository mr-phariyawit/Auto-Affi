# Sources — veg-thai-garlic (draft ref A4)

Comparison of the Thai light garlic type against the large-bulb (Chinese/Taiwanese) type. The contrast is drawn mainly on overall BULB SIZE and SKIN COLOUR, which is what the DOA sheet supports — not on a "small-clove" claim for Thai garlic.

## Visual detail -> source

| Drawn detail | Source / tag |

| Thai light type: white / off-white bulb and cloves | DOA plant sheet 133: light "khao mueang" type — "cloves and bulb white" [P] |
| Large-bulb type: markedly larger bulb, broad big cloves, pinkish-purple papery skin | DOA plant sheet 133: heavy type — "หัวใหญ่ กลีบโต เปลือกหุ้มสีชมพู" (large bulb, big cloves, pink skin), e.g. Chinese/Taiwanese variety [P] |

## Deliberately left out (unsourced / corrected)

- Thai garlic described as "small-clove" — AVOIDED. The DOA sheet's wording for the Thai light type's clove size ("กลีบเท่าหัวแม่มือ") is odd and is not quotable as "small", so no clove-size claim is made about the Thai type; the only clove-size statement drawn is that the large-bulb type has big cloves (sourced).
- Exact clove count or bulb diameter in numbers — not sourced.
- The purple-skinned northern medium type — not drawn; this card shows the white light type vs the large pink-skinned type only.
- GI status (กระเทียมศรีสะเกษ) — not a visual element; left to a HyperFrames caption with its own check.

## Acceptance criteria (check by eye)

1. Two clearly separate garlic groupings with empty paper between them, not touching.
2. Left bulbs read as off-white / pale; right bulb reads as pinkish-purple skinned.
3. The right bulb is visibly larger overall than the left bulbs, and its loose cloves are visibly broader.
4. At least one peeled clove is shown so the ivory flesh is visible.
5. Papery skin texture and clove divisions are legible on both.
6. No text, numbers or labels anywhere in the image.
