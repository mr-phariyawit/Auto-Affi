# วิธีใช้ Mannequin Poser (หุ่นไม้ 3D จัดท่า)

เปิดที่ https://claude.ai/artifact/9AhtJ19m85QVuuJU5L4V2k (ต้นทาง `poser.html` + `objlib.js` ในโฟลเดอร์นี้)

## หน้าจอ
- ซ้าย = ภาพ 3:4 ที่จะได้ตอนถ่าย snapshot (what you see is what you get)
- ขวา = แท็บ Prompt / Pose / Objects / Scene / Export
- มุมขวาบนของภาพ = โหมด gizmo: ย้าย (W) / หมุน (E) / ขนาด (R)

## กล้อง
- ลากพื้นหลัง = หมุนกล้อง · scroll = ซูม · ลากขวา/สองนิ้ว = เลื่อน
- FOV ปรับในแท็บ Scene ตำแหน่งกล้องถูกบันทึกลง JSON อัตโนมัติ

## จัดท่าเอง (manual)
1. คลิกข้อต่อบนหุ่น หรือกดปุ่มชื่อข้อต่อในแท็บ Pose (หัว, อก, แขนซ้าย, ปลายแขน, ขา, หน้าแข้ง …)
2. ลากวงแหวน gizmo เพื่อหมุนข้อต่อ หรือเลื่อน slider (ยกหน้า / กางออก / หมุน / งอศอก / งอเข่า)
3. "ลำตัว": หมุนทั้งตัว, ความสูงสะโพก (ยืน 0.98, นั่งสตูล 0.72)
4. ปุ่ม "สลับซ้าย-ขวา" กลับท่าเป็นภาพกระจก, "ท่าเริ่มต้น" รีเซ็ต
5. Esc = ยกเลิกการเลือก

## วัตถุในฉาก (แท็บ Objects)
- ปุ่ม "หุ่น" = ย้าย/หมุนหุ่นทั้งตัว, ปุ่มอื่น = กีตาร์ สตูล ไมค์ ผนัง สปอตไลท์ และวัตถุที่เพิ่ม
- เลือกแล้ว: W ย้าย / E หมุน-เอียง / R ย่อขยาย ด้วย gizmo หรือ slider (ตำแหน่ง xyz, เอียง x, หมุน y, เอียง z, ขนาดรวม/แยกแกน, สี)
- "ทำสำเนา" / "ลบ" (หรือกด Delete)
- เพิ่มจาก library: เลือกชนิดใน dropdown แล้วกด "เพิ่ม" (สตูล เก้าอี้ โต๊ะ แอมป์ ลำโพง ไมค์ ผนัง กล่อง ทรงกลม ทรงกระบอก กีตาร์ สปอตไลท์)
- กีตาร์: ตำแหน่งถือหน้า ≈ [0.02, 0.95, 0.26] หมุน [-10, 0, 22]; บนตักตอนนั่ง ≈ [-0.02, 0.86, 0.36] หมุน [-8, -10, 32]; สะพายหลัง ≈ [0.14, 1.08, -0.26] หมุน [0, 180, 55]

## สั่งด้วยข้อความ (แท็บ Prompt)
- พิมพ์ไทยหรืออังกฤษ แล้วกด "ใช้ Claude" ครั้งแรกจะมีหน้าต่างขออนุญาต (ต้องเปิดจาก claude.ai)
- สั่งได้ทั้งท่า วัตถุ กล้อง แสง ในประโยคเดียว เช่น
  - "นั่งสตูล กีตาร์บนตักขวา มือซ้ายจับคอกีตาร์ มองกล้อง แสง softbox ซ้ายบน"
  - "เพิ่มโต๊ะไม้เตี้ยด้านขวา มีแก้วกาแฟบนโต๊ะ และต้นไม้ในกระถางด้านหลัง"  ← วัตถุนอก library Claude จะประกอบจาก primitive ให้
  - "close-up ครึ่งตัว มุมต่ำ ฉากมืด spotlight จากบน"
- Claude เปลี่ยนเฉพาะสิ่งที่สั่ง ส่วนอื่นคงเดิม สั่งต่อเนื่องเป็นรอบๆ ได้
- "offline (keyword)" = ไม่ใช้ Claude รองรับคำพื้นฐาน (นั่ง ยืน เดิน ชูมือ กีตาร์ สะพายหลัง ไมค์ แอมป์ โต๊ะ เก้าอี้ ผนัง มองซ้าย/ขวา เงย ก้ม close-up เต็มตัว มุมต่ำ แสงซ้าย/ขวา อุ่น เย็น มืด)
- Presets: T-pose และ A/B/F/G ของ musician shoot

## แสงและฉาก (แท็บ Scene)
- key x/y/z = ตำแหน่งไฟหลัก (x ลบ = ฝั่งซ้ายกล้อง, y สูง = ไฟบน, y ต่ำ = แดดเย็น), ความแรง, ambient, สีไฟ, สีพื้นหลัง, สีพื้น

## ส่งออก (แท็บ Export)
- "ถ่าย PNG" = ภาพ 3:4 ไม่มี grid/gizmo ใช้เป็น pose reference ให้ GPT Image / Seedance ได้ทันที (ปุ่มบันทึกไฟล์ หรือคลิกขวา Save image)
- "Copy JSON" = ฉากทั้งหมด (ท่า วัตถุ กล้อง แสง) วางส่งให้ Claude ใน Claude Code ได้ หรือวางใน `poses.js` แล้วรัน `render.sh` เพื่อเรนเดอร์ headless
- "Load JSON" = วาง JSON ในกล่องแล้วกด เพื่อกลับมาแก้ท่าเดิม

## แนวทางใช้ร่วมกับ pipeline gen รูป
1. จัดท่า/ฉากใน poser → ถ่าย PNG
2. ส่ง PNG + JSON ให้ Claude พร้อมคอนเซปต์
3. Claude เขียน prompt: face-front = IMAGE 1, face-side = IMAGE 2, PNG หุ่นไม้ = IMAGE 3 (pose only), ชุด/กีตาร์ตามหลัง ระบุ "plain headstock, no logo"
4. gen ผ่าน OpenRouter gpt-image-2.5-sunburst (~$0.12/รูป) แล้วเทียบหน้ากับ ref ก่อนเก็บ
