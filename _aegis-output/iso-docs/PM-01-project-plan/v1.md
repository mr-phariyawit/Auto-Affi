# PM.01 Project Plan — Auto-Affi

> Regenerated 2026-06-08 from `SPEC.md` after the consolidated-knowledge hard-reset
> (commit `82c7fe5c`). This plan is **gate-centric and honest** per `SPEC.md` §17/§20:
> the prior build reached *code-complete, outcome-zero*. We do not repeat that.

## 1. Project Objective

Build an AI agent crew that runs (toward) 24/7 to: scout timely Shopee TH products →
match to viral trends → write a Thai-native script → generate a premium 9:16 short →
publish to social → collect metrics → self-learn via an LLM Wiki. The human is a
**supervisor + credential owner only** (`SPEC.md` §1.1).

**Phase-1 success is one fact, not a feature count** (`SPEC.md` §20):
> ONE real video live on a real platform with ONE real subId click recorded — **verified, not produced.**

## 2. Scope

### In Scope (Phase 1 — "single real loop closed", `SPEC.md` §13)
- Scout (Shopee) + Strategist + one Writer (no full Writers' Room debate yet)
- Storyboard JSON v1 → visual gen → Thai VO → post → master 9:16 ≤60s
- One publish target (IG Reel) + metrics polling + simple vector Wiki
- Compliance gates: disclosure, cleanroom audio, speed-guard (`SUPER_SPEC.md`, `SPEC.md` §10)

### Out of Scope (Phase 1)
- Full Writers' Room (5 sub-agents) — Phase 2
- Multi-platform (FB/YT) — Phase 2
- Temporal orchestration — re-decide deliberately (ADR-005 was accepted but never built; reality is in-process)
- Postgres/pgvector/ClickHouse — Phase 1 uses local/JSONL registry (`SPEC.md` §17.2)
- Paid ads, multi-tenant SaaS, human creators in loop (`SPEC.md` §1.3)

## 3. The Critical Path is Human Gates (NOT code)

Per `SPEC.md` §20, the project produced zero live outcome because **four human-only gates**
were never cleared. These are the real blockers and live in `human-queue.md`:

| # | Gate | Category | Blocks |
|---|------|----------|--------|
| G1 | Shopee Affiliate Program TH (apply; 1–7 day approval) | External | ALL live publishing + real subId |
| G2 | Meta Business + IG Creator + 60-day Graph token | External | IG publishing |
| G3 | Higgsfield account + credits | External | visual video gen |
| G4 | Runtime host (laptop cron → VPS/Temporal Cloud) | Identity | deploy + reliability SLO |

Engineering (Sprint 1) proceeds on **offline-buildable** work in parallel; the live-loop
exit criterion cannot pass until G1–G4 clear.
