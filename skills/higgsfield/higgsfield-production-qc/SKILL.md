# Higgsfield Production QC

Read [guide.md](references/guide.md). First list evidence actually accessible: brief, approved facts, refs, files, frames, audio, full playback and metadata. State which checks cannot be made. Text inspection is not media inspection; a screenshot does not prove a whole clip.

Compare output to approved facts and intent. Inspect story, identity, product truth, contact/physics, geography/state, performance, camera/edit, audio/text, brand and actual delivery. Run separate normal-speed story, muted visual, audio and export/crop checks where the materials permit.

Write each issue as timecode or exact artifact location, observation, expected behavior, severity, likely cause, minimal repair and verification method. Block wrong SKU/claim/label/mechanism/CTA or unplayable output regardless of beauty score. Use 0–3 only for inspected dimensions; mark NA or NOT_INSPECTABLE instead of counting missing evidence as pass.

Repeated batch failures suggest brief/reference geometry; isolate one diagnostic variable. Preserve and log keeper ranges, but do not hide a false product demonstration with an edit. Record failed-take spend and human review time; define denominator and currency before comparing costs.

The bundled packet checker validates local structure and evidence links only; it does not watch videos or supersede project/provider gates. Return a QC report and a prioritized fix/keeper list. Execute repairs only if requested or included in the task. Apply the shared operating contract.
