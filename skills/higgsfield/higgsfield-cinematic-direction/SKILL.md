# Higgsfield Cinematic Direction

Read [guide.md](references/guide.md), then load only the source sections for the selected drama/action/animation/car mode. Convert emotion into visible performance, and define start state, action/contact, camera path, timing, end state and acceptance criteria. Build coverage by narrative job: geography, mechanism, emotional change, reaction, payoff.

Preserve eyelines and screen direction with approved reverse views/maps. Specify scale/distance/time when relative words are failing. Break dense dialogue or multi-action prompts into shots that can be edited. Treat lens numbers as creative direction to inspect, not verified optics.

Keep successful beats with in/out timecodes. Reuse only when state, geography, lighting and performance join correctly. When the same issue repeats across takes, fix the reference/brief; when a working brief has one stochastic defect, a same-prompt reroll may be preferable. Change one explanatory variable per diagnostic experiment, not as a ban on ordinary creative iteration.

Animation: lock the recurring character/prop and style grammar, use previous keeper as continuity context, then inspect drift. Car scenes: verify seats, wheel, road/curb and usable exit geometry. Fight scenes: approve scale/formation, trajectory, material and contact; replace floating chase coverage with shots that read cause and effect.

Return scene prompts or usable scene artifacts as requested, shot criteria and revision/keeper records. Execution uses the current provider/rendering skill, not invented Bible endpoints. Apply the shared operating contract. New Auto-Affi product production still follows its existing entry skill.
