# Higgsfield Faceless Channel

Read [guide.md](references/guide.md). Choose a topic using dated evidence and a clear audience question. Build an evidence pack before script. Separate verified facts, inference, reconstruction and uncertainty. Make the opening promise answerable by the actual content.

Separate narration from visual prompts; each chapter contains a claim/question, evidence/example, takeaway and bridge. Fit scene changes to meaning and actual narration timing, not a compulsory number of scenes per minute. Avoid repetitive stock-like visuals and unearned open loops.

Inspect the full generated timeline and listen to the actual voice before saying it is delivered. Localization needs pronunciation, cultural terminology, timing and subtitle adjustment, not only translated text. Voice cloning is only an optional production capability and requires the relevant rights and user scope; reading the course did not enroll a voice.

Make title/thumbnail alternatives consistent with the answer in the script. Each short has one complete insight and an ending. Set a realistic cadence around quality and observed retention. Course RPM, revenue, YPP threshold, views and policy claims are historical examples; check current official policy when it affects release, without promising monetization.

Return the requested script/plan/package or inspected outputs, with sources and explicit inspection limitations. Route actual media creation to the available faceless/narration/rendering skills and apply the shared operating contract.
