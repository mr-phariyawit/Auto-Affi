# Higgsfield Brand Visuals

Read [guide.md](references/guide.md). Separate approved brand/product facts from invented concept designs. Establish a master identity set (logo variants, palette, voice, material and product geometry) before derivatives. Existing approved artwork takes precedence over a speculative redesign.

Choose deliverables by purpose: neutral views for product inspection, lifestyle for context, try-on for depiction, packshot for recognition, packaging/unboxing for sequence. Scope edits to preserve the selected product/wardrobe. Audit logo/text, color, shape, SKU and packaging states across all variants.

Fantasy motion or stress imagery does not substantiate durability, fit, waterproofing or performance. Synthetic testimonials must not be represented as real experience. Identify which depictions are concepts and which are fact-supported representations. Use each product's own references; never transfer a look or feature from a sibling SKU silently.

Produce the requested assets or ready prompts and a compact brand/format checklist. Use the currently available production tool/skill when executing; these course recipes are not API documentation. Apply the shared operating contract and existing Auto-Affi production gates when that route applies.
