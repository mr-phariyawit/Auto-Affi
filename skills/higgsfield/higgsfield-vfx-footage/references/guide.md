## Operating notes

Plate checklist: duration/framing; observed subject/camera path; source lighting; contact points; keep-list; exact change; timing trigger. Where source motion is unavailable, describe a plan and mark motion checks NOT_INSPECTABLE.

Appearance references define what a creature looks like; a mood reference defines lighting; neither should overwrite the real subject. Contact with stairs/rigs/grips in a plate is a physical scaffold for a new world. Relight is especially risky for face identity.

Inspect four integrations: moving depth (parallax), overlap (occlusion), light response (shadows/reflections), mechanical response (weight/contact/reaction). Compare anchors to the source throughout the changed interval.

An edit may be removal, addition, wardrobe, background, transition, new angle, reframe or upscale. Each needs different checks. An invented angle can hallucinate unseen geometry; upscale can hallucinate text; a 21:9 crop is not universally suitable for social.

Write exact keep/change constraints and the permitted output purpose. Verify current tools and plugin names before doing setup. The task of learning from a course is not authorization to install the course's integrations.
