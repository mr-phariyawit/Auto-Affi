# Higgsfield VFX on Footage

Read [guide.md](references/guide.md). Inspect the actual source plate when available; identify motion/camera, framing, light, contact and the precise requested change. Draft a keep-list, change region, observable trigger, appearance ref role, integration requirements and end state.

New effects must match source parallax, occlusion, cast/contact shadows, reflection, weight and timing. Do not let mood relighting drift the face or product. Use masks or targeted edits only through currently supported tools. A still frame does not verify motion across the clip.

Review the whole result at normal speed, then inspect suspicious contact/edge segments. Check that the retained anchors still match the source. Start/end frames can constrain a transition but do not prove the bridge is physically consistent. Reframe for the delivery channel; inspect important text and product at the actual crop. Upscaling can invent detail, so compare labels/faces to the source.

The course's plugin/product names are dated examples; do not install Quixel or invent a plugin identity based on the text. Verify the chosen current integration before execution. Return the requested edit or prompt plus inspection scope, failures by timecode and keeper ranges. Apply the shared operating contract.
