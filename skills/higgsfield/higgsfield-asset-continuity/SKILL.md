# Higgsfield Asset & Continuity

Read [guide.md](references/guide.md). Establish which things recur, which change, and the job of each reference. Use neutral readable sheets where useful, one dominant face identity, necessary real product angles, location 3/4/reverse views, layout maps, and explicit state transitions.

Do not fabricate hidden product details. A synthetic additional view is a design hypothesis until compared with real evidence. Scope identity refs to named subjects and mood refs to light/style. Treat a map as geometry, not as the output keyframe.

Prepare an asset register and state table, proportional to the task. Each reference has ID, source, role, version, approved details, uncertainty and affected shots. Motion-test the high-risk interaction before expanding, only when generation is authorized. If an outfit edit softens the face, repair that region rather than redesigning the person.

Return the pack or audit with exact unresolved angles/states, dependent shots, and what was actually inspected. Follow the shared contract at `../higgsfield-bible-director/references/operating-contract.md`; load only relevant source excerpts listed in the guide.
