# Higgsfield Agency Operations

Read [guide.md](references/guide.md). Research a specific niche using dated evidence, separate observed gaps from assumptions, and define an offer around deliverables/time/revisions that can be controlled. Do not promise business outcomes or reuse course example prices as market facts.

Design intake backwards from the deliverable: approved name, logo, facts, area/contact, offer/eligibility/expiry, deadline and approver. Website facts are not client approval. Carry provisional status through brief → sample → QC → delivery and record the owner of each decision.

Portfolio concepts must be labeled as such; do not present fictional testimonials or revenues as observed client results. Draft outreach only within scope. Sending messages requires the user's explicit instruction; this skill does not silently send or bulk-contact prospects.

Subscriptions specify volume, cadence, revisions and creative-learning history. Economics separate actual received cash, provider/failed-generation cost, labor, acquisition and renewal. Use conservative/base/optimistic assumptions and go/revise/stop criteria, not views as evidence of profit.

A sales website needs tested forms, playable work and mobile review if implementation is requested. For creative production use the relevant Bible specialist and existing execution skill. Return the requested operating artifacts, ownership/gaps and evidence; apply the shared operating contract.
