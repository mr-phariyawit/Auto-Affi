## Lesson from R19 (2026-10-07) — face shape cannot be fixed late

A pass-4 "FACE SHAPE AND EYES ONLY" edit on R18, with the style image attached as IMAGE 2, barely changed anything: the eyes got slightly warmer, but face width, jaw and apparent age stayed as in R18. The "Keep EVERYTHING … face geometry" frame overrides the request to change the geometry. If the face is not slim or young enough after pass 1, re-run pass 1 with stronger idealization (for example "about 24, noticeably slimmer face, sharper V jaw") or with a style image whose angle matches better, instead of adding a late pass.
