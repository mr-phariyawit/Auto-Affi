# JIAB signature style (operator-approved 2026-10-06)

Source: the 7 images the operator sent with "learn and remember this style, I like it". File locations are in `cast-library/jiab/style-bible-2026-10-06/README.md`. The full Thai write-up is in `docs/reference/pro-retouch-and-grooming-for-studio-portraits.md` §12.5–12.9.

| Element | Constant across every approved image |
|---|---|
| Hair | Medium-long, voluminous, natural waves, dark brown-black, swept up and to the side so the forehead shows, movement and healthy sheen. This replaced the earlier "keep his real short haircut" rule. |
| Skin | Smooth and luminous, warm-pink, no spots, no wrinkles, barely visible texture, not plastic. Glossy dewy glow, never oily hotspots. |
| Face | Slimmer than the real face, V jaw, visible cheekbones, reads about 25–28. |
| Eyes | Large, bright, smiling (Duchenne), defined lids, clear catchlights, fully open. Under-eye completely smooth and bright. |
| Brows | Thick, dark, straight to slightly arched, clearly defined. |
| Facial hair | Thin mustache plus a neatly shaped chin goatee, clean cheeks. |
| Lips | Natural rosy pink with a hydrated sheen. |
| Expression | Warm closed-lip smile, confident, head tilt 5–10°. Singing expression sheets are a separate use. |
| Light | High-key. Light-grey seamless (about #C8C9CB–#D9DBDD), soft wraparound light, gentle shadow on one side, no hard rim, no vignette. |
| Grade | Bright, clean, slightly warm, low-to-medium contrast. |
| Outfits | (1) black blazer + black tee + ivory trousers + black loafers, the default. (2) striped shirt + charcoal waistcoat + brown tie + charcoal trousers. (3) black military stage jacket with braid + black boots. |

## What the operator rejected, and why it matters

| Operator said | What it taught |
|---|---|
| "ไม่ได้อยากให้เหมือนตัวจริง… อยากได้หล่อกว่าตัวจริง" ("I don't want it to look like the real me… I want it more handsome than the real me") | Idealize. Recognisable is enough; exact likeness is not the goal. |
| "หน้ามีริ้วรอย ตำคล้า ตาง่วง คิ้วไม่ชัดเจน" (R6) ("wrinkles on the face, dark patches, sleepy eyes, brows not defined") | Textbook "keep pores, good day" retouch is too light. |
| "ยังไม่ผ่าน จงดูรูปนี้เป็นตัวอย่าง" (R8) ("still doesn't pass, look at this image as the example") | Words lost to a style reference. Low-key drama was the wrong direction. |
| "ต้องลบริ้วรอยทิ้งให้หมด เพิ่มความ glossy… เพิ่มสีผิวปาก" (R9) ("remove all the wrinkles, add more gloss, more lip colour") | Wrinkles zero, gloss up, lips rosier. This became pass 2. |
| "ยังคงมีริ้วรอยที่ใต้ตา และตายังคงคล้ำเหมือนคนไม่ได้นอน" (R10) ("there are still wrinkles under the eyes, and the eyes are still dark like someone who hasn't slept") | Under-eye needs its own pass. This became pass 3. |
| "ผิด … เบรคเรื่อง retouch ไว้ก่อน" (after soul-trainset-v1) ("wrong… pause the retouch work") | Retouched webcam images must not become Soul-ID training data. |
